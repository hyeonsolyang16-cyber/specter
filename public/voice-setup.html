음성 호출 설정

설정으로

준비물

설정 → 연동 탭에서 "구글 캘린더 연결"과 "개인 접속 토큰"을 먼저 완료하세요. 아래 설정에 토큰이 필요합니다.

아이폰 (단축어 앱)

  1. 기본 설치된 "단축어" 앱을 엽니다.
  2. 오른쪽 위 +를 눌러 새 단축어를 만듭니다.
  3. "동작 추가" → "받아쓰기 텍스트"를 검색해서 추가합니다.
  4. 다시 "동작 추가" → "URL의 콘텐츠 가져오기"를 추가합니다.
    • URL: https://specter-js8n.onrender.com/api/voice-command
    • 방법: POST
    • 헤더 추가: Authorization = Bearer 내_토큰
    • 요청 본문: JSON 선택 → 키 text에 값으로 위 "받아쓰기 텍스트" 변수를 넣습니다.
  5. 다시 "동작 추가" → "사전에서 값 가져오기"로 방금 받은 결과에서 reply 키를 꺼냅니다.
  6. 다시 "동작 추가" → "텍스트 말하기"를 추가하고, 방금 꺼낸 reply 값을 넣습니다.
  7. 단축어 이름을 정확히 "스펙터"로 저장합니다.
  8. 이제 "헤이 시리, 스펙터"라고 말하면 실행됩니다. (말한 뒤 몇 초간 받아쓰기가 진행되니, 이어서 바로 명령을 말하면 됩니다)

안드로이드

안드로이드의 구글 어시스턴트 루틴은 인증 헤더가 포함된 요청을 직접 보내는 기능이 없어서, "HTTP Shortcuts"(무료, Play 스토어) 같은 앱을 하나 더 설치해야 합니다.

  1. Play 스토어에서 HTTP Shortcuts 설치
  2. 새 단축어 생성 → URL에 https://specter-js8n.onrender.com/api/voice-command, 메서드 POST
  3. 헤더에 Authorization: Bearer 내_토큰, Content-Type: application/json 추가
  4. 본문(Body)에 {"text": "{{음성입력}}"} 형태로 설정 (앱 내 변수 입력 기능 사용)
  5. 홈 화면에 위젯으로 추가하면 아이콘 탭 한 번으로 음성 입력 → 일정 추가까지 됩니다

"헤이 구글" 같은 완전한 음성 호출은 안드로이드도 서드파티 앱만으로는 제한적입니다. 아이콘 탭 방식이 가장 안정적입니다.

참고

토큰은 비밀번호와 같습니다. 단축어 설정 화면 밖으로 캡처/공유하지 마세요. 유출된 것 같으면 설정 → 연동에서 즉시 재발급하세요.
